# Current capabilities and program scope

The project has a useful physics and presentation foundation, but it does not currently implement the proposed physiological nervous system. This document fixes the starting scope so future increments can distinguish existing capabilities, engineering hypotheses and experimentally supported behavior.

## Intended supported claims

The first deliverable is an educational, task-specific functional analogue: explicit observations influence a reproducible controller, which changes physical movement under documented body and environment conditions. Later increments can support muscle activity estimates, pathway impairment mechanisms and coherent examination demonstrations when their own evidence is sufficient.

Separate these claim levels in documentation and the interface:

1. **Engineering mechanism demonstrated:** a defined software and mechanics experiment behaves as specified.
2. **Reference supported educational behavior:** selected channels agree with independent data for a declared task and population.
3. **Clinically reviewed educational impairment:** a named illustration has evidence for its modeled mechanisms and stated limitations.
4. **Patient specific predictive behavior:** a separate research claim requiring additional data and validation; outside the initial program.

The program does not equate a learned controller with a biological cortex. Root localization, patient prognosis, rehabilitation response and arbitrary neurological injury prediction are not automatic consequences of a successful movement demonstration.

## Boundaries that guide implementation

Retain the existing MuJoCo pathway and shared engine. Use numerical controllers independently of conversational prompts. Keep atlas meshes, mechanical geometry, skin deformation and physiological parameters distinct but explicitly mapped. Existing clinical and patient bounds remain in force.

Future regions include the full pelvis to head chain, shoulder girdles, hands and digits, hips, knees, ankles and feet. Each increment declares represented, held, supported and unmodeled regions. No omission implies anatomical validity. Integrating more visual anatomy does not extend the validated task or population automatically.

The [architecture](02-system-architecture.md) describes proposed interfaces; the [validation plan](04-validation-and-experiments.md) defines the evidence each claim requires. Active movement failures remain in the existing master and current evidence records.
